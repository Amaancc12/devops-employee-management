# DevOps Employee Management Platform

An end-to-end DevOps project demonstrating modern software delivery and infrastructure practices.

## Project Goals

This project will demonstrate:

- Git and GitHub
- Application development
- Docker
- CI/CD
- Kubernetes
- Helm
- GitOps with Argo CD
- Infrastructure as Code with Terraform
- DevSecOps
- Monitoring and observability

## Architecture

The application will eventually consist of:

Frontend → Backend API → PostgreSQL

The application will be containerized and deployed to Kubernetes.

## DevOps Tools

- Git
- GitHub
- GitHub Actions
- Docker
- Kubernetes
- Helm
- Argo CD
- Terraform
- SonarQube
- Trivy
- Prometheus
- Grafana
